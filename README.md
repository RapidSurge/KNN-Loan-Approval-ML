# Credit Risk Prediction using KNN

## Project Overview

This project applies the K-Nearest Neighbors (KNN) machine learning
algorithm to a loan approval classification problem.

The objective is to predict whether a new customer should be approved
for a loan based on characteristics of historical customers.

## Variables Used

- Age
- Gender
- Monthly Income
- Credit Score
- Employment Years
- Existing Loans

## Methodology

1. Prepared historical customer data.
2. Selected relevant customer features.
3. Scaled numerical variables.
4. Calculated Euclidean distance between the new customer and historical customers.
5. Selected the 5 nearest customers (K = 5).
6. Used majority voting to generate the final loan approval prediction.

## Tools Used

- Microsoft Excel
- K-Nearest Neighbors (KNN)
- Feature Scaling
- Euclidean Distance
- Classification

## Files

- `KNN_Loan_Approval_Assignment.xlsx` — original assignment dataset
- `KNN_Loan_Approval_Solved.xlsx` — completed KNN analysis

This is an academic/portfolio recreation of an Excel-based machine-learning
